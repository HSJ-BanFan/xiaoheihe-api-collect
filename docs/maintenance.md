# 维护与离线验收

## 生成接口参考

运行 `python scripts/generate_reference.py` 根据公开 JSON 更新逐接口页与业务目录。运行 `python scripts/generate_reference.py --check` 检查生成结果是否过期，不写入文件。

运行 `python scripts/check_repo.py` 检查字段白名单、目录计数、CLI 路径一致性、内部 Markdown 链接、常见凭据模式、绝对路径和二进制文件。

项目存在 `.git` 时，扫描器以 `git ls-files --cached --others --exclude-standard` 枚举已跟踪文件与未忽略的新文件。已跟踪文件即使位于忽略目录中也会扫描。没有 Git 的临时测试目录才使用文件遍历并排除常见本地缓存。

被 `.gitignore` 排除的本地文件不是该枚举的待分发集合。扫描器不是发布归档器，也不证明所有敏感信息均被识别。发布前仍需核对实际待分发文件及忽略规则。

## 测试覆盖

`python -m unittest discover -s tests -v` 覆盖私有字段注入、错误白名单开放、链接缺失、二进制、绝对路径、凭据字面值、生成一致性、四类动态排行榜与群具名例外。

最初因生成器不存在而出现的测试收集错误，不是行为红测，也不计为 TDD 成功。后续负向注入测试在临时目录内运行，验证检查器会拒绝对应字段与文件。

抽样发现 POST 发布参数缺少带类型注解字典中的字段，且具名群读取参数缺少 query 位置。先加入回归测试并观察两项行为断言失败，再修复 AST 提取。修复后重跑完整根测试。

## 验收边界

2026-10-08 的授权线上验收覆盖了短信 App 登录和一组账号、上传、创作及互动功能。详见[线上验收报告](research/live-acceptance.md)。

该结果不验证全部 448 条参考记录、所有响应 schema、所有参数必填性、真实 HTTP 接口总量或平台授权范围。签名器仍由用户从本地 APK 资源构建，不随项目分发。

数据结构和页面完整性通过不代表上述事项已完成。
