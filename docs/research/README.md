# 研究报告

本目录保存可随项目发布的脱敏研究摘要。报告将源码观察、线上结果、分析推断和未验证事项分开记录，不包含账号凭据、验证码、账号 ID、手机号、原始响应、APK 或签名器 JAR。

| 报告 | 内容 |
| --- | --- |
| [接口目录范围](api-inventory.md) | 448 条参考记录的组成、证据等级和调用限制 |
| [登录与签名](authentication-and-signing.md) | App 与 Web 会话差异、签名器依赖和 CLI 登录路径 |
| [线上验收](live-acceptance.md) | 已验证功能、清理结果和仍未验证的范围 |

报告依据公开源码与本地发布验收记录整理。原始线上证据留在研究案件目录，不随公开仓库分发。
