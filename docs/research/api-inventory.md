# 接口目录范围

本报告说明公开接口目录记录了什么，以及这些记录不能证明什么。

## 已观察

- 当前快照有 448 条参考记录。445 条是固定 API 路径，另 3 条是辅助请求或模板。
- 快照包含 243 条通用 GET 白名单、167 条群路由和 9 条待复核路由。
- 目录按业务分组，每条记录列出路径、方法、认证观察、参数名、响应缺口和证据来源。
- 参数值、账号别名、账号 ID 和原始响应不进入公开快照。
- 通用 CLI 调用只接受 243 条白名单 GET。群读取和其他操作使用单独的具名命令及门禁。

接口数据来自静态代码观察、历史请求记录和逐条核对。每个接口页会标明目前可追溯的来源。标记为源码观察的请求构造不等同于服务端实时接受。

## 分析推断

业务分组和前缀有助于查找接口，但不能作为接口边界或权限边界。相同路径可能在不同客户端流程中使用不同方法、参数或认证方式。

通用 GET 白名单保留了历史项目的调用范围。HTTP GET 不保证没有服务器副作用，也不保证接口现在仍然存在。

## 未验证

- 目录不是平台接口全集。动态路径、未纳入样本的模块和服务端未公开接口可能缺失。
- 448 条记录没有逐条进行当前线上验收。
- 部分路径的方法冲突、参数必填性和响应 schema 仍待确认。
- 群、聊天室、搜索和部分社交路由没有完整的 CLI 调用覆盖。

离线目录可用以下命令检查：

~~~console
python scripts/generate_reference.py --check
python scripts/check_repo.py
python -m unittest discover -s tests -v
~~~

接口页和分组索引见[完整 API 目录](../README.md)。
